STEAL AN EGG OVERLAY V3 — SHARP + 3-CARD LAYOUT

SỬA TRONG V3:
- 10 thẻ được dựng lại từ CHÍNH ảnh gốc cards_original.png.
- Không đổi pet / tên / khung / bố cục bên trong thẻ.
- Card PNG được upscale lossless + sharpen để Browser Source rõ hơn.
- Tiền động bớt neon, màu xanh + viền đen gần ảnh gốc hơn và chữ lớn hơn.
- Weight + Mutation tự nhân lại ngay; Control hiện đầy đủ Base × Size × Mutation.
- Bật/tắt không clone, không tạo thêm ảnh.
- Khi CHỈ còn 3 thẻ Mecha Dreadscale + Luminous Eggs + Aetheron:
  hàng trên = Mecha Dreadscale | Luminous Eggs
  hàng dưới = Aetheron ở giữa
  khoảng cách giữa các thẻ = 6px.
- Chỉ 1 thẻ chuyển động 3D tại một thời điểm.

CÁCH UPDATE GITHUB:
1. Mở thư mục WEB_UPLOAD trong ZIP này.
2. Copy TOÀN BỘ file và thư mục cards.
3. Dán ghi đè vào thư mục local repo steal-an-egg-overlay.
4. GitHub Desktop -> Commit to main -> Push origin.
5. Chờ GitHub Pages khoảng 30-90 giây.
6. Mở Control và Overlay rồi nhấn Ctrl+F5.
