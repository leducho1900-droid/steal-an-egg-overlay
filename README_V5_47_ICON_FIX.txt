HUONG DAN SUA ICON QUA CAU TREN TASKBAR

Ly do bi hien hinh qua cau:
- Windows/Edge dang dung icon website mac dinh vi web chua co favicon/avatar trong root.
- Hoac ban dang ghim shortcut cu vao taskbar.

Da sua trong ban nay:
- Them favicon.ico bang anh avatar ban gui.
- Them avatar icon vao HTML/manifest.
- Cap nhat app desktop sang link v=548autoicon.

Cach cap nhat GitHub:
1. Mo thu muc WEB_UPLOAD.
2. Upload/thay cac file nay vao repo GitHub:
   - control.html
   - index.html
   - login.html
   - home.html
   - avatar.html
   - avatar_overlay.html
   - admin.html neu co dung admin
   - favicon.ico
   - manifest.webmanifest
   - thu muc assets/avatar_icon.png, avatar_icon_192.png, avatar_icon_512.png
3. Commit changes.
4. Doi 1-3 phut.

Cach sua icon duoi taskbar:
1. Bam chuot phai icon qua cau duoi taskbar.
2. Chon Unpin from taskbar / Bo ghim khoi thanh tac vu.
3. Dong app cu.
4. Mo thu muc STEAL_AN_EGG_DESKTOP_APP.
5. Chay INSTALL_APP_DESKTOP.bat.
6. Mo icon Steal An Egg Control moi ngoai Desktop.
7. Neu muon de duoi taskbar: chuot phai icon dang mo -> Pin to taskbar.
